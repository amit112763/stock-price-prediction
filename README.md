# 📈 Stock Price Prediction

A Streamlit-based stock price prediction application built with Python and Machine Learning.

The application fetches historical stock market data using Yahoo Finance, performs feature engineering, trains a Linear Regression model, evaluates its performance, and generates short-term price forecasts.

## 🚀 Features

- 📊 Historical stock price analysis
- 📈 7-day, 30-day and 50-day moving averages
- 📉 Volatility and daily return analysis
- 🤖 Linear Regression model
- 📏 Model evaluation using:
  - RMSE
  - MAE
  - R² Score
- 🔮 Short-term stock price forecasting
- 📋 Historical and forecast data tables
- 📥 Download stock data as CSV
- 🌐 Interactive Streamlit dashboard

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Yahoo Finance (`yfinance`)
